What we learned about the graph

In long chains, every top-k edge spans more than 32 residues

100%

of 91,295 non-local edges in 60 test chains with N ≥ 100 fall in the >32 band

The score f(a,b) / (p(d) + ε) is ruled by p(d), which falls about 1,300× with separation, while f(a,b) moves only about 2×.

Residue type only breaks ties inside the farthest band, so mid-range partners (5–32 apart) never get a non-local edge.

Fix, as the proposal planned

Count contacts per (a, b, band) to get p(a,b,d), then rank by p(a,b,d) / p(d). The score then measures enrichment within each band.

Re-ran the edge selection on the test split with the saved contact table

When we checked which edges the graph actually picks, we found a side effect. Because the band mean p(d) drops by three orders of magnitude with separation, while the amino-acid term only changes by a factor of two, dividing by p(d) pushes every pick into the farthest band. For chains of 100 residues or more, all non-local edges are more than 32 apart. Residue type still matters, but only within that band. The proposal's three-way table p(a,b,d) would fix this, because the ratio would then compare a pair with its own band.
