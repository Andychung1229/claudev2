The prior is an input feature, not a fixed attention weight: the GAT can learn how much to trust it.

COMP 5222 · ContactGAT

Every edge, including self-loops, gets a 10-dimensional feature vector: the contact prior, the normalised separation, a one-hot of the six separation bands, and flags for local and self edges. A small MLP turns this into 8 numbers that enter the attention score. The key design choice from the proposal is that the prior is a feature, not a hard-coded weight, so the model decides how much it matters.
