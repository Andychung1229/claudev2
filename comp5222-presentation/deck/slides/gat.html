Method · Step 4

An edge-aware graph attention network reads the graph

ATTENTION SCORE (per head)

u(i,j) = LeakyReLU( a_src · Wh(i) + a_dst · Wh(j) + a_edge · MLP(e(i,j)) )

NORMALISE OVER NEIGHBOURS ONLY

α(i,j) = softmax over j ∈ N(i) of u(i,j)

UPDATE (residual + LayerNorm)

h′(i) = ELU( LayerNorm( h(i) + Σ_j α(i,j) · Wh(j) ) )

READOUT

ln Rg = MLP( mean h ‖ max h ‖ log N )

[~1:00] Now, how does the model read this graph? It is a graph attention network that also reads edge features. For each edge, every attention head scores it from three parts: the sending node, the receiving node, and the edge features. That third term is where the contact prior enters. It is an input to the attention score, not a fixed weight, so the model learns how much to trust it. The scores are normalised only over each node's neighbours, and each node takes a weighted sum of their messages, with a residual connection and LayerNorm. After two layers, we pool the whole chain: mean, max, and log of the length. A small MLP then predicts log Rg. The whole model has under nineteen thousand parameters.
