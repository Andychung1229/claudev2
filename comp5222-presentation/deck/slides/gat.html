Method · Step 4

An edge-aware graph attention network reads the graph

ATTENTION SCORE (per head)

u(i,j) = LeakyReLU( a_src · Wh(i) + a_dst · Wh(j) + a_edge · MLP(e(i,j)) )

NORMALISE OVER NEIGHBOURS ONLY

α(i,j) = softmax over j ∈ N(i) of u(i,j)

UPDATE (residual + LayerNorm)

h′(i) = ELU( LayerNorm( h(i) + Σ_j α(i,j) · Wh(j) ) )

READOUT

ln Rg = MLP( mean h ‖ max h ‖ log N )

The prior steers attention

Contact frequency enters the score as an edge feature, not as a fixed weight. The model learns how much to trust it.

Small on purpose

2 layers × 4 heads × 16 channels: 18,721 parameters.

Length stays visible

log N goes straight into the readout, next to mean and max pooling.

Tian & Chung · COMP 5222

[~1:10] Step three is the model: a graph attention network that also looks at edge features. For each edge from j to i, every attention head computes a score from three parts: the transformed features of node i, of node j, and the edge features passed through a small MLP. That is where the contact prior enters. It is an input to the attention score, not a fixed weight, so the network can learn how much to trust it. The scores are normalised with a softmax over the neighbours of i only — the edges we built. Then each node takes a weighted sum of its neighbours’ messages, with a residual connection, LayerNorm and an ELU. After two layers we pool over the whole chain: the mean, the max, and log of the length, so the model always knows how long the chain is. A small MLP maps this to log Rg. The whole model has under nineteen thousand parameters, which is tiny compared with protein language models. In the code we implement it as dense attention with an edge mask, which is equivalent to running on the sparse graph.
