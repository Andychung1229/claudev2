Problem

Why predicting Rg from sequence is hard

01

No static structures to learn from

AlphaFold learned from crystal and cryo-EM structures in the PDB. IDRs have none, so it outputs low-confidence ribbons or wrongly collapsed shapes.

02

Current models read a 1D string

Scalar predictors (ALBATROSS, IDP-Bert) and 3D generators (idpGAN, STARLING, IDPFold) all treat the sequence as tokens. Pairwise physics must be learned from scratch, and generators need costly sampling to get Rg.

03

Not much labelled data

The Human IDRome has 28,058 simulated chains. Large sequence models are over-sized for this, and it is hard to see which residue pairs drive their predictions.

Tian & Chung · COMP 5222

[~0:55] So why is this hard? First, there is no structural data to learn from. AlphaFold works because the PDB holds a huge number of solved structures. Disordered regions do not crystallise, so AlphaFold gives low-confidence ribbons or shapes that are wrongly collapsed. Second, the dedicated IDP methods split into two families. Scalar predictors like ALBATROSS and IDP-Bert map sequence straight to Rg. Generative models like idpGAN, STARLING and IDPFold produce 3D ensembles, but then you must sample many structures to estimate Rg. Both families read the sequence as a one-dimensional string, so the network has to rediscover the pairwise physics from scratch. Third, data. The largest consistent dataset, the Human IDRome, has about twenty-eight thousand simulated chains. A very large model is a poor match for that, and it is hard to explain which residue pairs drive its predictions.
