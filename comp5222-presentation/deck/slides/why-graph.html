Motivation

Rg is set by pairs of residues, so we hand the model the pairs

Sequence-only models

1D CNNs and protein language models read the chain as a string of tokens. Long-range contacts have to be learned from about 19k scalar Rg labels.

Our residue graph

Contact statistics from simulations become edges and edge features. The GAT only learns how to weigh them, with 18,721 parameters.

Proposal hypothesis: an explicit, sequence-derived interaction graph helps graph-level regression when labels are limited.

COMP 5222 · ContactGAT

Rg comes from the balance between chain entropy and pairwise interactions between residues. A sequence model has to rediscover those pairwise effects from scalar labels alone. We move that pairwise knowledge into the input: the graph already tells the model which residue pairs tend to touch, so the network can stay small. This is a hypothesis we test, not something we assume.
