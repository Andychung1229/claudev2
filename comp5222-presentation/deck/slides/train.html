[~0:30] We trained it on a split that really tests unseen proteins. We split seventy, fifteen, fifteen by protein, not by sequence: all regions of the same UniProt protein stay in one split, so the test set holds proteins the model has never seen. We minimise squared error on log Rg with AdamW and early stopping. Training takes about thirteen minutes on one consumer GPU. The validation curve is noisy; a learning-rate schedule should fix that.
