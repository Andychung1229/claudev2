Node

21 features: amino-acid one-hot (20) plus position i / (N − 1).

Self-loop

Each residue attends to itself. Its contact prior is set to 0.

Local edge

1 ≤ |i − j| ≤ 2. Keeps the chain connected.

Non-local edge

|i − j| > 2. Each residue keeps its top 8 by f(a,b) / (p(d) + ε), then union.

Example: experimental sequence exp3_0000 · edges from build_sparse_graph

Each residue is a node with a one-hot amino-acid code and its relative position. Edges come in three kinds. Self-loops let a residue keep its own state. Local edges join residues one or two apart, so the chain is always connected. Non-local edges are the interesting part: for every residue we score all partners more than two apart by f(a,b) divided by the band mean p(d), keep the top 8, and make the result undirected. The picture uses k equals 1 so it stays readable; with k equals 8, a chain this short is almost fully connected.
